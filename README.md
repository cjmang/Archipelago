# Golden Sun: The Lost Age

This is the Archipelago world for Golden Sun: The Lost Age, which is based on
the [gs2-randomizer](https://gs2randomiser.com/) by Karanum.

## Releases

To see the current release of the APWorld, click [here](https://github.com/cjmang/Archipelago/releases)

## Poptracker

You can find the Poptracker pack for this game [here](https://github.com/cloudofdarkhole6/GSTLAPopTracker)

## Setup and Usage

Follow the [Setup Guide](worlds/gstla/docs/setup_en.md). It will walk you through installing the APWorld, generating
options and patching the game.
For more information on how the randomization works for this game and what items and locations get randomized, check out
the [Usage Guide](worlds/gstla/docs/en_Golden%20Sun%20The%20Lost%20Age.md)
